# Rubricas Comuns de Boletos de Condomínio

> Lista das rubricas mais comuns em boletos de condomínio residenciais, com classificação e base legal.

---

## Legenda

- **Ordinária**: Despesa de rotina, responsabilidade do locatário (art. 23)
- **Extraordinária**: Despesa estrutural ou excepcional, responsabilidade do locador (art. 22)
- **Variável**: Depende do contrato ou situação específica

## Notas

1. **Classificação padrão**: Esta lista representa a classificação padrão para contratos residenciais. Contratos comerciais podem ter classificações diferentes.

2. **Exceções contratuais**: Alguns contratos podem estabelecer regras diferentes. Sempre verificar a ficha do contrato antes de aplicar a classificação padrão.

3. **Rubricas não listadas**: Se uma rubrica não estiver nesta lista, deve ser classificada com base na Lei 8.245/91 (arts. 22-23) ou marcada como pendência.

4. **Atualização**: Esta lista deve ser atualizada sempre que novas rubricas forem identificadas nos boletos recebidos.
